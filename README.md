# nTv

[English](README.en.md) · [Linux.do](https://linux.do/u/buhanzhe) · [恩山论坛](https://www.right.com.cn/forum/thread-8484303-1-1.html)

`nTv` 是一款面向 Android 电视、电视盒子、平板和手机的横屏直播播放器，重点优化遥控器操作、老旧设备兼容性和央视直播稳定性。

## 主要功能

- 内置央视网、央视频等直播频道，并支持多线路自动选择。
- 支持最高、适中、最低三档清晰度；只有一路时直接播放。
- 提供稳定、适中、低延迟三档直播模式。
- 使用 IJK 播放器，支持硬件解码、自动选择解码器和兼容软解。
- 支持自适应画面比例和全屏拉伸。
- 支持遥控器、触摸屏、网页遥控器和手机飞鼠。
- 支持 M3U、M3U8、TXT 在线频道列表。
- 可显示时间、日期、网速和播放调试信息。
- 支持开机自启动、在线更新和异常自动恢复。
- 最低支持 Android 4.0。

Android 8.0 及以上系统如果阻止安装，请根据系统提示，允许当前浏览器或文件管理器“安装未知应用”。

## 遥控器操作

- 上键、下键：切换频道。
- 确认键、菜单键：打开频道列表。
- 返回键、菜单键：关闭频道列表。
- 播放/暂停键：暂停或继续播放。
- 数字键：按频道序号快速切台。
- 频道列表关闭时连续按两次返回键：退出应用。

如果习惯相反的切台方向，可在设置中开启“上下键反转”。

## 触摸操作

- 点击画面左侧：打开频道列表。
- 点击画面右侧：打开设置网页。
- 在画面左侧上下滑动：调节音量。
- 在画面右侧上滑：切换到下一个频道。
- 在画面右侧下滑：切换到上一个频道。

平板或手机旋转后，视频画面会跟随设备方向调整。

## 网页管理

电视与手机连接到同一个局域网后，可在应用菜单中查看网页管理地址或二维码。

网页管理端可以：

- 选择频道和线路。
- 调整清晰度、直播稳定性和画面比例。
- 设置时间、日期、网速及调试信息。
- 添加或更新在线频道列表。
- 配置开机自启动和遥控器行为。

管理端口从 `9966` 开始；如果端口被占用，应用会自动尝试下一个端口。请以应用实际显示的地址为准。

## 手机飞鼠

在网页管理端进入“手机飞鼠”，开启电视光标后即可使用：

- 陀螺仪：像遥控器一样移动或转动手机来控制光标。
- 触控板：滑动控制光标，滑动越快移动越快。
- 点击、返回和光标居中等快捷按钮。

首次启用陀螺仪时，请允许浏览器访问动作与方向传感器。使用完毕后可再次点击按钮关闭陀螺仪，以降低手机耗电和发热。

## 推荐设置

- 直播稳定性：优先选择“稳定”。
- 清晰度：网络和设备性能允许时选择“最高”。
- 画面比例：优先选择“自适应”。
- 解码方式：优先使用自动硬解；出现黑屏或花屏时尝试兼容软解。

## 常见问题

### 切台后短暂缓冲

优先使用“稳定”直播模式，或降低清晰度。应用会等待必要分片准备完成后再开始播放。

### 手机打不开管理网页

确认电视和手机连接到同一个局域网，并使用应用当前显示的 IP 和端口。部分路由器的访客网络会禁止设备互相访问。

### 陀螺仪无法开启

使用系统浏览器打开飞鼠页面，并允许动作与方向权限。部分浏览器需要安全网页环境才能提供传感器数据。

### 硬件解码黑屏

先尝试自动选择解码器；仍无法播放时切换到兼容软解。不同电视芯片和系统固件的解码兼容性可能不同。

## 说明

请仅播放您有权访问的直播内容。频道可用性、清晰度和线路数量可能随上游服务变化。
