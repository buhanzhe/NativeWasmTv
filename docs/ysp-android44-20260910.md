# Android 4.4 央视频恢复播放

设备：ADB `8ba8ceb8`，Samsung SM-G3608，Android 4.4.4。

原包央视频 CCTV-1 源报 `auth-http-0`。该解析器使用站点插件提供的 HTML/JS 发起 WebView XHR，并非未安装插件。央视网按用户反馈可用，本次未改其播放流程。

在 Android 5 以下，为解析器的内部 API 页面提供受限的原生 HTTP 桥接，使用现有 Ku9HttpClient/NetworkClient。仅允许央视频鉴权、直播和令牌三个 HTTPS 接口，不跟随重定向，响应限制 1 MB。站点请求正文与签名算法仍来自原插件。Android 5 及以上保持原网络流程。

覆盖安装 `output/release-20260910-ysp44/nTv.apk`，保留应用数据。三类接口均返回 HTTP 200，日志包含 `First video frame rendered decoder=hardware channel=CCTV-1 综合`。媒体状态 prepared/playing=true、outputFps=25；截图确认 1920×1080 H.264 画面。证据：`.codex-tmp/ysp44-fixed.log`、`.codex-tmp/ntv-ysp44.png`。

构建 ARM32/ARM64 正式包通过；仅 ARM32 在上述设备验证。未做长时间播放稳定性测试。测试完成后 force-stop 应用并检查进程，移除临时 ADB 转发与设备截图。
