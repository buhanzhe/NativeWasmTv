# 管理网页平板判断

按用户指定，`ManagementActivity.isTablet(Context)` 仅以 `Configuration.smallestScreenWidthDp >= 600` 判断平板，移除原默认屏幕方向判断。

点击播放画面右侧仍进入管理网页：平板使用横屏右侧竖向面板，WebView 渲染尺寸保持 720×1280，点击面板外侧关闭；手机全屏竖向显示。

验证：Android 9 模拟器上现有布局测试通过。最小宽度为 480 dp 时全屏竖向；临时调为 720 dp 时右侧面板视觉宽度 405 px、窗口 1280×720，触控坐标和点击外侧关闭通过。599 / 600 dp 边界及横竖方向组合测试通过。测试后恢复模拟器原密度、退出应用并关闭测试服务器。

32/64 位正式包构建、签名和混淆检查通过：`output/release-20260909-tablet600/`。
