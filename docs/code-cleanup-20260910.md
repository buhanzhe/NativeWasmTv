# 代码梳理与精简（2026-09-10）

## 范围

对主应用 96 个 Java 文件做声明与调用扫描，并检查近期涉及的投屏退出、文件选择、管理网页轮询和插件兼容路径。扫描只用于产生候选项，删除前额外检查了测试与脚本引用。不是所有分支的实机覆盖，也不是整体架构重写。

## 仍应逐步治理的结构问题

- MainActivity 梳理前约 12,531 行，混合播放、接管、设置接口、频道与 UI。下一步适合按会话生命周期和频道选择两个职责分批抽离，而不是一次改写全部状态。
- HlsProxyServer 约 3,522 行，兼顾下载、解密和流输出。重构前需要单独覆盖取消、按序输出、坏分片及断线场景，当前不为减少行数调整传输或解密参数。
- 插件和网页解析仍有不同系统版本的兼容分支。不能仅凭名字相近合并；央视频 Android 4.4 修复尤其需要保留。
- 工作区有大量先前未提交修改。本次保留这些修改，没有清理历史包、用户配置或执行提交/推送。
