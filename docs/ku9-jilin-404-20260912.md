# Android 4.0.4 Ku9 吉林频道实测

设备 emulator-5564，API 15；覆盖安装当前 ARM32 release，未清除应用数据。
使用用户提供的 gh-proxy.org 地址，7 个源均取得播放器首帧。每项观察到首帧即进入下一项，不代表长期稳定性测试。

|频道|首帧观察秒|QuickJS 执行毫秒（含脚本请求）|
|---|---|---|
|吉林卫视|3.22|516|
|吉林都市|1.08|219|
|吉林生活|2.16|273|
|吉林影视|1.11|233|
|吉林乡村|2.13|697|
|吉林综艺文化|1.06|229|
|长春综合|1.08|253|

旧安装包的频道数据库版本为 1，与设备已有版本 2 不匹配，导致保存频道源失败。当前包 DATABASE_VERSION=2，覆盖安装后导入正常。
当前 Ku9ScriptResolver 在 Android 5.0 以下使用原生 QuickJS，MainActivity 在普通网页限制之外独立处理 Ku9 源，没有 API 15 禁用条件。未新增不必要的放行改动。
测试结束恢复原频道源配置、停止应用并删除临时列表。
