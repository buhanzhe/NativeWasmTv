# 网页与本地多媒体切换

实现：保留接管连接和 WebView 文档。临时投送本地图片、视频或音乐时暂停网页媒体和编码输出；多媒体结束/返回后恢复网页编码，不重新导航网页。音乐转换为 AAC（或按设置保留 AAC/AC-3）并配 H.264 静态播放画面。原生文件选择沿用当前电视地址；连续选文件按顺序结束旧串流再开始新串流，保持接管连接。电视验证原接管会话 ID，旧接收端会提示更新。

返回优先级：媒体设置弹窗 > 多媒体 > 管理网页导航。支持手机系统返回、管理网页返回、飞鼠电视返回、电视返回。编码失败也恢复原网页。页面脚本保存原来的静音/暂停状态，并覆盖同源 iframe 和后来新增的媒体元素；跨域 iframe / 特殊 Web Audio 内容还需要专项实机音频验证。

验证：
- ARM32 / ARM64 release 构建通过。
- 22 项管理网页回归测试通过。
- tests/media-pause.test.js 验证原静音/暂停状态、同源子页面、新增媒体及恢复。
- Android 17 → Android 7.1.1：在网易云音乐网页投送期间，原生选择 30 秒本地 WAV；发送进度 2500ms，接收端识别 H.264 / AAC 44100Hz，播放结束后恢复网易云音乐，takeoverReceiverUrl 保持不变。
- 早期同时保留网页编码器的方案出现接收错误串流，已改为暂停网页编码器后再开始多媒体。
- 最终版本连续替换文件、主动返回与网页声音恢复尚未完整实机复测；手机切到了其他应用后停止模拟点击，避免干扰用户。
- 测试后退出两端应用，并恢复测试前 webCastAudio=true。
