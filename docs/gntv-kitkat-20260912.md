## 修改与证据

Android 4.1–4.4 改用已内置的 TLS 1.2 实现（原来仅 API 14–15 使用），替换系统旧 TLS 的协议/密码套件开关包装。Android 5.0+ 保持系统实现；未增加库。
修复后香港卫视、TVB 星河、TVBPlus、明珠、翡翠、天映及 4 个 Astro 均出现真实首帧。中天新闻、凤凰中文、CGTN 英语、钱江都市抽测仍正常。
4 个宁夏源日志明确返回 Upstream HTTP 403；电脑请求宁夏公共亦返回腾讯云 WAF 拦截页。按要求未对源站拒绝访问进行处理。
河北 4K：OMX 日志记录 width(3840), height(2160)，setParam sum(8294400) > max resolution(3010560)，硬解 configure error -38，随后 VideoCodec: avcodec, h264。系统接着结束多个进程及应用。内核日志权限不足，未将内存不足作为已确证根因。
原始日志：.codex-tmp/gntv-results/01.log–21.log、gntv-baseline-rest/22.log–55.log、gntv-tls-retest/；原包第一次批处理在第 21 项应用退出后产生的 22–55 控制错误已排除，以上使用恢复后的真实逐项结果。
原频道源配置已从 .codex-tmp/gntv-original-state.json 恢复。
恢复原配置后，CCTV-1 央视网线路也已验证首帧。测试结束已停止应用并删除设备上的临时 GNTV 列表。
