# Ku9 / CJS 设备兼容测试

四台设备的 666 项均已执行，包含单独补测后的结果。`NATIVE_VIDEO_FRAMES` 表示实际播放器输出视频帧；`WEB_MEDIA_PLAYING` 表示网页媒体元素进入播放且时间已推进。页面加载成功、HTTP 200 都不等同于播放成功。此轮按当前清晰度设置验证起播，不代表所有清晰度、长时间稳定播放或声音已人工确认。

## 覆盖范围

- 本地 cjs：120 个去重频道入口，包括频道表与央视描述文件对应入口。
- webSourceM3U8：仓库全部三份频道/网页列表，保留每项来源；相同 URL 只执行一次。
- 公开 Ku9 合集：11 种脚本，每种至多选择两个不同频道参数，属于代表性兼容样本。
- 合并后共 666 个唯一入口。原生/脚本入口首轮等待至多 20 秒，网页入口 12 秒；重点失败项复测放宽至 45 秒。
- Ku9 脚本使用冻结的仓库字节，通过 App 本地脚本加载器执行。原始下载 URL 另有桌面网络预检；播放矩阵不包含每台设备的远程脚本下载可靠性测试。

## 已定位问题与修复

- 共享返回解析支持脚本返回的 JSON 字符串，保留脚本明确报告的错误。
- 普通 Ku9 支持 `webview` 与 `jscode` 返回；脚本在目标文档加载后执行，同一文档防重复注入，切频道清除。
- HTTP 请求去除地址两端的空白；兼容嵌套请求头。杭州公开脚本曾把 M3U8 行末换行带入请求，修复后出帧。
- 河北脚本使用官网 HTTPS 接口的 Date 响应头签名。4.4 设备时钟慢约四小时，原两小时有效期 URL 已过期，上游返回 403。
- 修正本地吉林列表中多余的路径斜杠。

## 测试环境和限制

- Android 9 模拟器的实际 WebView 为 Chrome 68；小米 6 为 WebView 119，不能只比较 Android 版本。
- Android 4.0.4 保留现有低性能设备网页限制；纯 Ku9/QuickJS 可运行。API 17 之前不启用不安全的 JavaScript Java 桥；最小网页脚本注入与桥接脚本引擎是两条不同路径。
- 公开 `ku9js.js` 返回的网页脚本含箭头函数、`for...of` 等新语法；协议已接受该返回格式，但旧 WebView 的语法/DOM 能力仍有限，不能据此承诺在 4.4 起播。公开咪咕、快直播等样本会返回业务错误；原样保留在 CSV 中。
- Android 9 首轮部分项目被其他应用切至后台影响，已单独复测相关央视入口。
- 小米 6 从编号 305 附近开始断网：无默认路由、DNS 不可用。已重新连接原来保存的 Wi-Fi，并从编号 305 重测；旧断网区间单独归档，不参与统计。
- 4.4 的央视频网页入口首轮按网页上限等待 12 秒，20 项未取得起播；延长至 45 秒后 19 项起播，CCTV-10 明确解析失败。旧超时记录保留，但不作为最终失败结论。
- 4.4 的两路 4K 样本（编号 177、205）与西湖明珠网页（610）单独复测仍出现挂起/进程退出。4K 日志已进入解码输出阶段；没有可用 native 崩溃堆栈，内核日志读取返回 Operation not permitted，不能确定是内存不足还是固件解码/渲染问题。这三项未修复，未计为通过。
- 4.4 的央视网页（301）补测起播；两路新疆网页（587、591）补测未再进程退出，但仍无起播证据。小米 6 的网易云课堂（241）补测页面加载成功；它是普通网页，不计入直播起播。
- Android 17 未连接 ADB，未测试。
- 四台设备均测试 ARM32 APK；本轮没有验证 ARM64 APK。APK 与测试输入散列见 [构建记录](build-manifest.json)。
