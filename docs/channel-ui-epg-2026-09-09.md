# 频道菜单、EPG 与管理网页外观

## 本次改动

1. 管理网页增加跟随系统、日间、夜间三档外观。入口在管理首页，保存在当前浏览器；页面切换和刷新沿用设置。旧 WebView 可以手动切换，CSS 不依赖变量。
2. 保留本机上下键反转换台，增加遥控器 `CHANNEL_UP/DOWN` 的归一化；修复接管状态下电视向手机转发上下键时忽略反转配置的问题。菜单内上下导航方向保持自然，媒体控制器的“上一个/下一个”语义不反转。
3. 节目菜单采用半透明深蓝背景、简化的栏目背景；打开菜单时隐藏底部信息卡，避免重叠。
4. 节目单默认收起，点击标题栏或在频道列按右键展开，收藏入口移到节目单顶部。收起状态不绑定节目列表、不测量节目标题宽度。
5. EPG 解析保留本地当天零点以来的节目，显示列表只展示当天并去重。按本地自然日复用下载缓存，同一天冷启动不重复下载；过日后启动检查更新。请求失败时保留旧数据，本进程同源当天不反复请求。
6. EPG 启动任务等待加载/缓冲状态连续结束至少 3 秒，再以后台线程优先级读取缓存或请求网络，不额外轮询 CPU 占用率。该策略避免与首次加载直接竞争，不承诺任何固定 CPU 百分比。
7. 底部信息卡采用紧凑蓝色透明矩形，显示频道号、名称、播放信息，以及有 EPG 数据时的当前/下一档节目。M3U `tvg-logo` 随频道、收藏、远程频道及冷启动快照保留；缺失、下载失败或不支持的台标隐藏且不留空位。只为当前频道在加载结束后请求台标，限制下载大小、解码尺寸、队列及缓存数量。
8. 频道目录数据库通过新增字段保存台标，升级使用 `ALTER TABLE`，保留已有频道与收藏。
9. 数字换台逐位等待从 1.2 秒延长至 3 秒，按确认键可立即提交；三位数字输满仍立即提交。
10. 打开选台菜单后定位当前频道至中央，包括首尾频道。Android 4.4 在列表布局完成后的下一轮消息中定位，避免布局覆盖滚动位置；仅在首尾补足需要的留白。

### 台标缓存与滚动条补充

- 成功解码的台标转为 PNG，保存在应用缓存目录 `channel-logos-v1`。使用频道名称（去首尾空格）的摘要作为文件名，名称中有路径符号也不会产生目录穿越。
- PNG 自保存起有效 24 小时，内存缓存遵循同一有效期。读取不会续期；同名频道的台标地址变化也优先复用有效缓存。
- 先读取内存，再由后台线程读取本地 PNG，最后才请求网络。文件过期、损坏或解码失败时重新获取；只有成功解码的图片才写入 PNG。临时文件写完后再替换正式缓存，磁盘写入失败不影响本次显示。
- Android 4.4 独立回归：首次加载请求 1 次，重新创建加载器并更换 URL 后仍为 1 次；缓存过期及损坏分别触发重新下载，且图片正常显示。验证 24 小时边界及系统时间倒退不会延长缓存。
- 节目组、频道、EPG 三列都设置为不显示滚动条，保留列表滚动及遥控器导航。

### EPG 台标补充
