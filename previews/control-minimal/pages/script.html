安装脚本

选择本机的 .user.js 或 .js 文件（UTF-8，含 UserScript 元数据头，最大 256KB）。每次导入新增一项，不覆盖已有脚本。
Greasy Fork Greasy Fork 镜像 OpenUserJS GitHub
也可从公开 HTTPS 地址导入。请仅安装可信脚本；导入后先预览，确认保存后才安装，总开关开启时生效。
